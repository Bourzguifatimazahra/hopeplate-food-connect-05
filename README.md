# HopePlate 🍽️

## Description
HopePlate is a food connection app designed to help users discover and connect over meals, promoting sharing and community engagement.

## 🛠️ Technology Stack
- **TypeScript** - 91.75%
- **JavaScript** - 2.67%
- **HTML** - 3.28%
- **CSS** - 0.92%

## ✨ Features
- User-friendly interface
- Meal sharing and discovery
- Community engagement tools
- Real-time notifications
- Secure authentication

## 🚀 Live Demo
Visit the live application: [hopeplate.netlify.app](https://hopeplate.netlify.app/)

## 📥 Installation & Usage

### Prerequisites
- Node.js 16+
- npm or yarn

### Setup
1. Clone the repository:
   ```bash
   git clone https://github.com/Bourzguifatimazahra/hopeplate-food-connect-05.git
   cd hopeplate-food-connect-05
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm start
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser
